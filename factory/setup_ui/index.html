Delivery workflow

  1. Issue queueRead labeled issues from GitHub or GitLab.
  2. Intake & specificationScope the issue and define what must pass.
  3. BuildImplement in a separate worktree.
  4. ChecksRun your test, lint, or build commands.
  5. Independent reviewCode and security every run. UX and UI for interface work.
  6. Handoff & draft PR/MRSummarize evidence. Publish when requested.
  7. StagingAutomatic after passing gates, once trusted CI is connected.
  8. ProductionYour manual merge authorizes release through CI.

A failed check or review sends work back to build. The factory stops after the configured round limit.
